# 🛡️ ShieldScan — Complete Final Year Project

## 📁 Folder Structure
```
ShieldScan/
├── backend/     ← Node.js API Server
├── frontend/    ← Website (HTML/CSS/JS)
└── extension/   ← Chrome Extension
```

---

## ✅ STEP 1 — Backend Chalao

```
cd ShieldScan/backend
npm install
```
Windows mein:
```
copy .env.example .env
```
Mac/Linux mein:
```
cp .env.example .env
```
Phir:
```
npm start
```
✔️ Ye dikhega: ShieldScan backend → http://localhost:5000

---

## ✅ STEP 2 — Frontend Kholo

VS Code mein:
1. frontend/index.html par right-click
2. "Open with Live Server" click karo
3. Browser mein khulega: http://localhost:5500

---

## ✅ STEP 3 — Chrome Extension

1. Chrome mein: chrome://extensions
2. Developer mode ON karo
3. "Load unpacked" click karo
4. ShieldScan/extension folder select karo
5. Done! 🛡️
